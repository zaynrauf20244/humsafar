# Saath

Your daily commute circle — web + mobile (PWA).

## Roles

1. **Driver** — multi-step registration (CNIC, licence, car, route)
2. **Passenger** — commute profile → find Circle

## Features

- Matched Circles, driver rotation, chat, backup driver, credits
- Mobile-first UI + phone frame on desktop
- Installable PWA (Add to Home Screen)

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). On phone: browser → Add to Home Screen.
